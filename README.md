💙 Apemigos API — Plataforma sobre Esclerose Múltipla

A Apemigos API é o backend oficial desenvolvido para apoiar a ONG Apemigos, uma iniciativa voltada à conscientização, informação e apoio a pessoas com Esclerose Múltipla.

O objetivo deste projeto é centralizar e gerenciar conteúdos confiáveis, como notícias e materiais educativos, contribuindo para a divulgação de conhecimento acessível sobre a doença, seus tratamentos e avanços científicos.

🚀 Tecnologias Principais

Java 21

Spring Boot 3

PostgreSQL

Spring Data JPA

MapStruct

Lombok

OpenAPI (Swagger)

💡 Sobre o Projeto

Esta API foi construída seguindo boas práticas de desenvolvimento, priorizando a qualidade, a clareza e a acessibilidade da informação.
Ela serve como base para os serviços e aplicações da plataforma Apemigos, que visa promover educação, empatia e qualidade de vida para pessoas que convivem com Esclerose Múltipla.
